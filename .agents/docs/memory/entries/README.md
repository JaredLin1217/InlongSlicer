# Project Memory Entries

Detailed project-local memory entries live in this directory.

Each entry should be linked from `../index.md` and use this format:

```text
# YYYY-MM-DD - Short title

- Trigger:
- Context:
- Cause:
- Fix / Rule:
- Verification:
- Reuse when:
```

Do not add entries for generic preferences, guesses, or unrelated project lessons.
